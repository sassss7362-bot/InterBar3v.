# InterBar 2.0 (Spigot / Paper 1.16.5 і новіші)
Збірка: mvn clean package -> target/InterBar.jar -> plugins/

Скорборд справа з двома пунктами, що змінюють один одного (профіль / статистика),
боссбар зверху, TAB з рангами. Усе в config.yml (кольори, градієнти, рядки).

Команди:
  /bar                           - меню (скорборд / боссбар / TAB)
  /bar toggle <sidebar|bossbar|tab>
  /bar ether [give|take|set <гравець> <сума>]   - ефіри
  /bar reload
